# MAE 263F — Homework 4: Axial Response of a Helical Spring Using Discrete Elastic Rods
**Author:** Yuchen Wang (Ph.D. in Mechanical Engineering, UCLA)  
**Date:** November 2025  
---
## 📘 Project Overview
The objective of Homework 4 is to model the axial response of a helical spring
using the three-dimensional Discrete Elastic Rod (DER) formulation and to extract
its effective axial stiffness from dynamic relaxation simulations. The spring is
constructed from its geometric and material parameters and discretized with
sufficient resolution to capture bending, twisting, and stretching behavior along
its centerline.
