## 📘 Project Overview
This homework models a **simply-supported aluminum beam** subjected to a **point load** using an **implicit dynamic solver**.  
The simulation compares numerical results against the **Euler–Bernoulli beam theory**, highlighting the advantages of the implicit numerical method in capturing **large deformation effects** beyond the limits of linear theory.
